| Table 11 \| Implementation standards to ensure accuracy and reliability of GFR assessments using creatinine and cystatin C Report eGFR in addition to the serum concentrations of <sup>fi</sup>ltration markers using validated equations. Report eGFR rounded to the nearest whole number and relative to a body surface area (BSA) of 1.73 m<sup>2</sup> in adults using the units ml/min per 1.73 m<sup>2</sup>.
