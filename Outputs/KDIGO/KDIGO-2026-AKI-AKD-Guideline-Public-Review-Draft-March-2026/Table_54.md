| Table 54 \| Strategies to mitigate adverse events associated with ultrafiltration Strategy        Reduce unnecessary fluid administration in critically ill patients to avoid excess accumulation.       Cool dialysate to  \leq 3 6 ^ { \circ } \mathrm { C } .       Prescribe net ultrafiltration  ( \mathrm { U F _ { N E T } } )  by body weight rather than target total volume.      Prescribe a slower  \mathrm { U F _ { N E T } }  and continuous gradual fluid removal. Avoid high  \mathrm { U F _ { N E T } }  while patients are receiving hemodynamic support (i.e., vasopressors).      Review routinely and regularly the UFNET targets and response to fluid removal.      Avoid or minimize prolonged exposure to high  \mathrm { U F _ { N E T } }  (short-term high  \mathrm { U F _ { N E T } }  may be indicated and necessary to address life-threatening complications of fluid overload). Adapted from Murugan et al.<sup>1016</sup> |
