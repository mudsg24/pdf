| Table 16 \| Balance of bene<sup>fi</sup>ts and harms |
| When there was evidence to determine the balance of medical bene<sup>fi</sup>ts and harms of an intervention to a patient, conclusions were categorized as follows: |
| For statistically signi<sup>fi</sup>cant bene<sup>fi</sup>t or harm, report as “bene<sup>fi</sup>t [or harm] of intervention”. |
| For non–statistically signi<sup>fi</sup>cant bene<sup>fi</sup>t or harm, report as “possible bene<sup>fi</sup>t [or harm] of intervention”. |
| In instances where studies are inconsistent, report as “possible bene<sup>fi</sup>t [or harm] of intervention”. |
| “No difference” can only be reported if a study is not imprecise. |
| “Insuf<sup>fi</sup>cient evidence” is reported if imprecision is a factor. |
