| Class | Side Effects |
| :--- | :--- |
| ACE inhibitors | Cough, hyperkalemia |
| ARBs | Much less frequent hyperkalemia compared with ACE inhibitors |
| CCBs | |
| DHP CCBs | Pedal edema, headache |
| Non-DHP CCBs | Constipation (verapamil), headache (diltiazem) |
| Diuretics | Frequent urination, hyperglycemia, hyperlipidemia, hyperuricemia, sexual dysfunction |
| Central α-agonists | Sedation, dry mouth, rebound hypertension, sexual dysfunction |
| α-Blockers | Pedal edema, orthostatic hypotension, dizziness |
| β-Blockers | Fatigue, bronchospasm, hyperglycemia, sexual dysfunction |
| Potassium channel openers | Hypertrichosis (minoxidil); lupus-like reactions, pedal edema (hydralazine) |

ACE, Angiotensin-converting enzyme; ARBs, angiotensin receptor blockers; CCBs, calcium channel blockers; DHP, dihydropyridine.
